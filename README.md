# Loveli Bot - نسخه 3

ربات انتشار خودکار پست‌های تلگرام با قابلیت‌های:
- 🔗 پروکسی MTProto داخلی
- ✏️ ویرایش پست‌ها در لحظه (مثل Edit تلگرام)
- ⭐ استخر ایموجی کپشن (تا 200 ایموجی)
- 🎯 ایموجی ثابت + رندوم اول کپشن
- 🎲 فوتر رندوم
- 📊 آمار و مدیریت منابع

## نصب
\`\`\`bash
bash install_proxy_bot.sh
\`\`\`

## اجرا
\`\`\`bash
systemctl enable --now pubbot
\`\`\`
